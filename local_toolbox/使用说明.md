# 电商财务对账与商机雷达一体机

解压后双击 `双击启动_电商对账与商机雷达.bat` 打开中文窗口；或双击 `双击启动_本地网页版.bat`。完整绿色包自带 Windows x64 Python 3.11 和 Excel 模块，无需管理员安装、不必另装 Python。

## 四个功能

1. 订单与流水核对：支持 CSV / TSV / XLSX 第一张活动表，自动识别常见订单号与金额列，也可填写手动映射。检测漏收款、无源流水、多笔入账、重复订单及金额不符。Excel 导出异常行标红。
2. 客户需求线索：读取国内公开社区内容，或导入含“标题、内容、来源链接”的本地 CSV/XLSX；按需求词规则排序。没有命中需求词的内容明确标为普通线索。
3. 热词与商品报价：获取国内公开热榜快照，或导入“商品名称、销售价、采购成本、品类”报价表。运费与手续费率可选。利润为报价估算，未计广告、退货、税费、人工；热词没有商品价格、销量或利润承诺。
4. 代码体检：选择项目目录，只读扫描 Python/JS/TS 源码，不执行内容；常见密钥脱敏。Python 使用 AST + 正则，JS/TS 使用正则。未命中不等于绝对安全。

## 试用与激活

所有计算功能均可试用，未激活每次只导出当前结果前 10 行，不提供分页导出。机器码在顶部，发送该 8 位机器码给卖家，收到 `VIP-XXXX-XXXX-XXXX` 后在窗口输入即可永久解锁本机全量导出。激活校验离线进行，重启后仍有效；更换电脑需另领匹配码。激活文件保存在当前用户的本地应用数据目录。

## 长订单号与金额

科学计数法在有效位数完整时可以展开。已被表格软件四舍五入或截断的长订单号无法凭空恢复，本工具会将其标为“输入待核实”，不参与自动匹配；请从原系统重导文本订单号。CSV 导出长编号前加文本保护前缀，XLSX 直接保存为文本。金额采用十进制定点、四舍五入到分；退款保留负数。多笔流水不直接认定为重复收费，需检查拆单、退款等业务背景。

## 样例与隐私

“载入随附样例”只用于功能验活，样例均为人工构造，不作为真实交易或市场业绩。账单与源码在本机处理，只有点击公开采集时才请求国内公开数据源。网络接口不可用时明确报错，不伪造实时数据；本地三类导入分析与代码扫描仍可使用。

网页版上传地址仅在本机 127.0.0.1。关闭服务小窗口会停止服务。Tk 窗口可从资源管理器拖入订单/流水表，或用选择按钮；拖错时可直接重新选择。

支持 Windows x64；不支持旧 .xls 文件，请先另存为 .xlsx。单表最多 100000 行、50MB，单次目录扫描最多 5000 个源码文件、单文件 1MB。
